# Power BI report

Put the report here **only** as `Sales_Dashboard_DEMO.pbix`, after it has been refreshed on the demo data
(`python demo/run_demo.py`) and checked with the privacy checklist in
[docs/power-bi-guide.md](../docs/power-bi-guide.md#privacy-checklist-before-you-share-a-pbix).

A `.pbix` stores a full copy of the data it was last refreshed with. `.gitignore` blocks every other `.pbix`.
